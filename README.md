# FluorineOS Artwork

Artwork and branding package for FluorineOS 0.0.1.

## Contents

- 3840x2160 AMOLED SVG wallpapers
- Plymouth boot splash
- fastfetch configuration and logo
- Calamares installer branding

## Package

- Name: fluorine-artwork
- Version: 0.0.1
- Architecture: all

## Build

```sh
dpkg-buildpackage -us -uc -b
```

This repository is part of the FluorineOS project.
